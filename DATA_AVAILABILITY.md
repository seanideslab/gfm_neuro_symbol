# Data Availability Statement

## Recommended manuscript wording after public release

The simulation configurations, processed envelope-level trajectory data, scenario-level split identifiers, trained model parameters, extracted symbolic equations, and analysis scripts supporting the findings of this study are publicly available at [GITHUB_URL], release [RELEASE_TAG], and are archived at [DOI]. The repository also contains scenario-level summary results, instability-diagnostic labels, symbolic-regression settings, modal-analysis configuration, and controller-HIL timing metadata required to reproduce the reported tables and principal analyses. Proprietary MATLAB/Simulink, Simscape Electrical, OPAL-RT, and vendor-specific components are not redistributed; instead, non-proprietary parameter/configuration files and processed outputs are provided to permit independent reimplementation.
