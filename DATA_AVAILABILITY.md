# Data Availability Statement

## Current manuscript wording for this preparation release

This GitHub repository is a preparation package containing configurations, summary tables, analysis scripts, and explicitly labeled non-evidence examples. It does not currently provide the complete processed trajectory archive, exact scenario split IDs, trained model checkpoints, or raw per-seed GSR/SymPy exports. Those omissions prevent a claim that the manuscript results are fully reproducible from this repository. Proprietary MATLAB/Simulink, Simscape Electrical, OPAL-RT, and vendor-specific components are not redistributed.

The representative symbolic equations and `seed_coefficients_raw.*` values are derived from a common structure and corrected supplied coefficients; they are not raw GSR/SymPy exports and must not be described as such.
