# Symbolic Export Status

Raw per-seed GSR/SymPy exports are not included in this preparation release.

`seed_coefficients_raw.csv`, `seed_coefficients_raw.json`, and `seed_equations_derived_from_common_structure.csv` contain corrected supplied values and equations reconstructed from one common representative structure. They are not outputs exported from GSR or SymPy and must not be presented as five independent symbolic fits.

Before a public reproducibility claim, add `seed_equations.csv` and `seed_coefficients.csv` directly from each actual training/symbolification run, including seed IDs, equation IDs, canonical-structure status, and provenance.
