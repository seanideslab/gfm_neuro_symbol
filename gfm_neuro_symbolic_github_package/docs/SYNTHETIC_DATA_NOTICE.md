# Synthetic Data Notice

Files under `data/synthetic_examples/` are **synthetic test fixtures only**.

They are provided to:
- test plotting and parsing code;
- demonstrate expected CSV schemas;
- exercise latency/Prony analysis scripts before the measured logs are copied into the repository.

They must **not** be cited as measured experimental observations, raw DSP timing logs, raw Prony bootstrap outputs, or evidence supporting manuscript performance claims.

For the final public release, replace synthetic examples with the actual recorded files or leave them explicitly marked as examples.
